# Drafts (legacy/manual)

Denne mappe er kun til frie manuelle noter eller legacy-udkast.

Nye automatiserede artikler skal ikke gå fra løs Markdown direkte til live. Brug i stedet:

1. assignment
2. `sources/*.json` fact ledger
3. `content/articles/*.json`
4. quality gates + generator

Intet i `drafts/` publiceres automatisk.
