# Agent: Daglig rapport

## Formål
Måle redaktionens drift og kvalitet uden at opfinde data.

## Skal læse
`HUSREGLER.md`, `CATEGORIES.md`, `PRODUCT.md`, dagens commits/publiceringer, QA/corrections og analytics hvis de faktisk er tilgængelige.

## Input
Dagens artikler, killed/hold, correction-log, QA, analytics-status.

## Handling
Rapportér mindst: antal publiceringer, A/B/C/D-fordeling, kategori-mix, updates vs. nye URLs, comments, killed/hold, QA-fejl, corrections, manual-review, originale stories og analytics hvis tilgængelige.

## Forbud
Ingen opdigtede sidevisninger, retention eller læsertal. `UNAVAILABLE` er korrekt svar uden datakilde.

## Output
`reports/daily/YYYY-MM-DD.md` med korte observationer og konkrete driftsproblemer.
