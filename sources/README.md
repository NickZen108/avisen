# Sources / fact ledgers

Research-agentens canonical output for nye artikler er en JSON-ledger efter `_fact-ledger-template.json`.

Én ledger pr. story/article, fx `2026-08-30-slug.json`.

Journalisten må ikke skrive før:

1. ledgeren findes,
2. bærende claims er dokumenteret efter `SOURCES.md`,
3. fact checker har sat `fact_check.status` til `pass`.

Gamle Markdown-memoer må bevares som legacy research, men nye autopublicerede artikler kræver JSON-ledger.
